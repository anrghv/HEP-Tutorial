# HEP Tutorials

Learning notes and hands-on examples for HEP tools. This repo is a personal study space for ROOT, PyROOT, and related utilities, and acts as a compact learning resource.

## Goals

- Build practical familiarity with ROOT and PyROOT
- Keep minimal, runnable examples
- Track notes, commands, and pitfalls as I learn

## How I plan to organize things

- Short notes in Markdown
- Small scripts and notebooks focused on one concept
- Datasets or sample ROOT files only when needed

## Topics I want to cover

- ROOT basics (I/O, TTree, histogramming)
- PyROOT workflows
- Plot styling and presentation
- Basic analysis patterns

## Usage

This is a learning repo, so each folder or file should be self-explanatory. If you are browsing, start with the newest notes or the top-level notebooks/scripts.
